# PetStore — Relatório de Execução dos Testes

## 1. Objetivo

Documentar os resultados registrados durante a atividade **STLC Practice – Test Execution & Reporting**, realizada na Mate Academy, utilizando o carrinho de compras da aplicação JPetStore.

Este relatório foi organizado a partir dos resultados presentes no Checklist original, preservando os status registrados.

## 2. Ambiente de teste

* **Aplicação:** JPetStore
* **Funcionalidade:** Carrinho de compras
* **Sistema operacional:** Windows 11
* **Navegador:** Google Chrome
* **Versão da aplicação registrada:** Demo
* **Data exibida no relatório original:** 8/7/2026

Durante a organização da documentação para o portfólio, foi identificada uma divergência entre o Checklist e a aba Report da planilha original.

Este documento utiliza a contagem dos status individuais registrados no Checklist.
