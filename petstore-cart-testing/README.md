# PetStore — Testes Manuais do Carrinho de Compras

## Sobre o projeto

Projeto prático de testes manuais realizado durante minha formação em QA Engineering na Mate Academy.

A atividade utiliza a aplicação JPetStore e acompanha as quatro fases do STLC (Software Testing Life Cycle): análise de requisitos, desenvolvimento dos testes, execução e relatório de resultados.

## Objetivo

Verificar se as funcionalidades do carrinho de compras atendem aos requisitos estabelecidos, identificando comportamentos diferentes dos resultados esperados e documentando os defeitos encontrados.

## Aplicação testada

* **Aplicação:** JPetStore (ambiente de estudos da Mate Academy)
* **Funcionalidade:** Carrinho de compras
* **URL:** https://jpetstore.mate.academy/actions/Catalog.action

## Escopo dos testes

* Acesso e navegação pelo carrinho.
* Exibição de produtos e cálculo do subtotal.
* Adição e remoção de produtos.
* Atualização e validação de quantidades.
* Limite de cinco unidades do mesmo produto.
* Validação de estoque.
* Comportamento do carrinho entre sessões.
* Redirecionamento para login e checkout.

## Ambiente registrado

* Sistema operacional: Windows 11.
* Navegador: Google Chrome.
* Versão da aplicação informada nos relatórios: Demo.

## Ferramentas e técnicas

* Google Sheets para elaboração do checklist, execução e relatórios.
* Testes funcionais manuais.
* Cenários positivos e negativos.
* Análise de requisitos.
* Análise de valores-limite.
* Registro e classificação de bugs.

## Resultados da atividade

Conforme os registros do checklist original:

| Indicador                   | Resultado |
| --------------------------- | --------: |
| Testes planejados           |        37 |
| Testes aprovados (Passed)   |        26 |
| Testes reprovados (Failed)  |        10 |
| Testes bloqueados (Blocked) |         1 |
| Bugs documentados           |         4 |

Os resultados foram recuperados da documentação original da atividade. O relatório estatístico original apresenta divergências em relação ao checklist, identificadas durante a revisão para o portfólio.
